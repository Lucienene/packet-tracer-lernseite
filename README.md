# Packet-Tracer-Lernseite

Eine schlichte deutschsprachige Lernhilfe für die praktische Einrichtung von HTTP, HTTPS, SSH, DNS und DHCP in Cisco Packet Tracer.

**Website:** https://lucienene.github.io/packet-tracer-lernseite/

## Inhalt

- Schrittfolgen mit den englischen Feldnamen aus Packet Tracer
- Beispiel-Auftragssätze mit Zuordnung zu den Einstellungen
- Zusammenhängender Übungsauftrag und Beispiel-Adressen
- Fehlerhilfe für Namensauflösung, Adressvergabe und Webzugriff
- Kopierbare HTML- und SSH-Beispiele

Die Beispieladressen und Zugangsdaten sind erfunden und für das dargestellte Übungsnetz gedacht. In einer Klassenarbeit gelten die Werte und Anforderungen aus dem jeweiligen Aufgabentext.

## Lokal öffnen

Die Website besteht aus statischem HTML, CSS und JavaScript. Sie benötigt keinen Build-Schritt und keine externen Schriftarten oder Bibliotheken. `index.html` kann direkt geöffnet oder über einen statischen HTTP-Server bereitgestellt werden.

## Veröffentlichung

GitHub Pages veröffentlicht den Stammordner des Branches `main`. Die Datei `.nojekyll` deaktiviert die Jekyll-Verarbeitung.
